Rule reference

Eighteen static detection rules. Every rule ships with a bad fixture that must trigger and a good fixture that must not.

HUC001 — hidden Unicode

Zero-width characters and bidirectional controls can make rendered text differ from what a parser or an agent reads. Bidirectional controls score high because they enable Trojan Source style tricks. A UTF-8 BOM at byte zero is not flagged.

PIN001 — prompt injection

Matches injection phrases such as "ignore previous instructions" or "reveal the system prompt" inside tool and skill description fields only. Scoping to descriptions keeps the false-positive rate manageable.

REM001 — remote downloads in skills

Covers curl or wget piped into a shell or interpreter, PowerShell Invoke-Expression chains, base64 decode into a shell, certutil downloads, long base64 literals, and remote git or pip sources inside skill files.

MCP001 — auto-approve flags

Flags autoApprove: true and permission-skipping flags such as --dangerously-skip-permissions, --yolo, and --no-auth in MCP server definitions.

MCP002 — filesystem root mounts

A filesystem server given /, ~, or a drive root can read anything the process can. Repo-relative mounts are fine.

MCP003 — unpinned dangerous commands

Extends UNP001 beyond package runners to docker, kubectl, helm, curl, wget, and shells used as MCP server commands without a version pin.

MCP004 — sensitive env vars

Flags server definitions that receive environment variables with credential-like prefixes: cloud keys, database URLs, tokens, certificates.

UNP001 — unpinned packages

npx, uvx, and bunx run whatever the registry serves today. A pin such as pkg@1.2.3 or pkg==1.2.3 satisfies the rule; @latest does not.

SEC001 — embedded credentials

Provider formats (OpenAI, GitHub, Slack, AWS, Google, Bearer) score high. Generic assignments require a Shannon entropy above 3.5 so placeholders such as "changeme" do not fire.

SHC001 — shell command execution

String-form eval, exec, and compile, os.system, subprocess calls with shell metacharacters or string formatting, and deprecated command modules.

NET001 — exfiltration channels

Cloud metadata addresses, pastebin and webhook endpoints, tunneling services, raw sockets, DNS resolution, HTTP calls carrying data payloads, and long encoded fragments in URL paths.

FSY001 — filesystem access

Traversal sequences, writes and deletes, SSH keys and certificates, env and secrets files, and archive extraction with zip-slip risk.

ENV001 — credential access

Iteration, serialization, printing, or logging of the whole environment, direct reads of cloud and database variables, and shell expansions of long uppercase variables.

PRI001 — escalation and injection

Docker and Kubernetes privileged modes, host namespace sharing, docker socket access, LD_PRELOAD, ptrace attach, Windows registry run keys, scheduled tasks, and encoded PowerShell.

OBF001 — obfuscation

Base64 round trips combined with compression, PowerShell encoded commands, XOR ciphers, long encoded literals, and Cyrillic, Greek, or fullwidth homoglyphs.

SUP001 — supply chain

Unpinned installs, wildcard versions, git-sourced dependencies, custom package indexes, and install-time scripts in package definitions.

CFG001 — config and template injection

Template delimiters, unsafe YAML python tags, dunder references in config, connection strings with inline credentials, and hardcoded secrets in config files.

TOO001 — tool calling

Tools named shell, exec, or similar; descriptions that advertise arbitrary execution; autonomous agent frameworks; disabled strict mode.

CRY001 — cryptography

MD5 and SHA1, DES and RC4, AES-ECB, RSA keys at 1024 bits or below, the random module for security purposes, disabled certificate verification, and hardcoded keys or IVs.

Rule severities are advisory. Run cairnlock rules --verbose for the same table in your terminal.
